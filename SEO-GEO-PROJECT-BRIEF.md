# Numerosenletras.org — SEO/GEO project brief

## Scope, domain, cost and keyword governance
- Canonical brand and domain: https://numerosenletras.org
- Language: Spanish (es). Country-specific financial pages are Spanish content localized by law/format, not separate fully translated languages.
- Stack: Astro static HTML + React client islands + Tailwind; no backend, paid API or monthly infrastructure required.
- **Keep the existing live primary keyword phrasing**. Do not invent search-volume, KD, CPC or traffic estimates. Confirm future additions with owner-supplied keyword/SERP evidence.
- Content accuracy is a release-blocking requirement because words may appear in financial documents.

## Indexation, canonical and international rules
- Stable trailing slash, HTTPS, canonical origin in Layout.astro and astro.config.mjs.
- Sitemap generated by @astrojs/sitemap; robots.txt includes sitemap index.
- HTML documents have direct H1 and static explanatory content; React hydrates inputs and results.
- Query parameters (?n, ?formato, ?moneda) are shareable form state and canonicalize to the owning route. **Do not generate indexable permutations** of these parameters.
- Single 'es' content language and x-default fallback currently self-point to each page; do not add es-MX/es-ES alternate hreflang without separately localized reciprocal URL equivalents.
- Country pages are justified by concrete different currencies, output rules, examples and applicable official references; audit uniqueness before expansion.
- Font pages are a distinct topical silo, cross-linked selectively rather than substituted for financial intent.

## Structured data and GEO
- Existing JSON-LD includes Organization, WebSite, WebApplication, FAQPage, BlogPosting and BreadcrumbList where applicable.
- Match markup with visible content; FAQ markup does **not** guarantee rich results in Google.
- Important pages should answer a concrete question early; include an example, input assumptions, precision limits and authoritative references.
- Cite RAE/ASALE for grammar and official legislation for legal assertions. Each changing legal claim must be reviewed and dated before presenting as authoritative.
- No invented case studies, ratings, official certifications or AI visibility scores.
- llms.txt is optional interoperability information; it is **not** a Google Search / AI Overview requirement.
- Google-Extended training permissions do not affect Google Search rankings.

## Verification and measurement
- Automated: typecheck, tests, static Astro build and scripts/check-built-site.mjs for 20 canonical pages, H1/description/schema, static files and internal links.
- Production/manual: sample desktop/mobile, status 200/404, redirects, consent behavior, clipboard/audio/print, P95 INP, LCP, CLS, sitemap/robots reachability.
- GSC: compare 28-day clicks, impressions, queries, pages and countries after deployment. Do not infer performance changes from code changes alone.
- No publication of additional indexed long-tail pages until SERP intent, uniqueness and usefulness are validated.
