# numerosenletras.org

Spanish number-to-words and financial amount converter. Production domain: **https://numerosenletras.org**. Repository: `garrison2025/numerosenletras1`.

## Technical stack

Astro 7 static site, React 19 islands for interactive tools, Tailwind 4, 16 currency configurations, 5 country-specific financial pages and 2 Unicode typography tools. No backend, paid API or database is required for conversions.

## Local development

Use Node 22 and Bun.

```bash
bun install --frozen-lockfile
bun run dev
bun run lint
bun run test
bun run build
bun run verify:site
```

The post-build audit checks 20 canonical routes, local anchor targets, H1, descriptions, JSON-LD scripts, and crawl assets. GitHub Actions runs all four validation steps on pushes and pull requests.

## Number and locale correctness

- LA display: `1,234.56`. ES display: `1.234,56`.
- Parse once using the selected locale, normalize to canonical decimal-dot strings, then convert.
- Integer part: up to **15 digits**. General numeric fractional part: up to **12 digits**. Money: **at most 2 fractional digits**.
- No scientific notation, malformed grouping, silent currency truncation or silent rounding.
- Core engine: `src/utils/numberToLetters.ts`; shared parser: `src/utils/parseLocalizedNumber.ts`; country financial formats: `src/utils/countryFinancialFormats.ts`.
- Country examples reflect selected banking *conventions*, not an official legal certification. Verify critical paperwork with the receiving bank or authority.

## SEO/GEO and visual governance

Follow `AGENTS.md`, `DESIGN.md`, `SEO-GEO-PROJECT-BRIEF.md`, `SEO-GEO-QUALITY-GATE.md` and `QA-CHECKLIST.md`. Preserve existing approved core keywords, URL slugs, canonicals, country pages, and artwork.

## Privacy and monetization

Conversions are performed in-browser. Preference/history storage is opt-in. `public/ads.txt` is currently a **placeholder**; replace with the actual publisher information for this specific domain if and when this site is connected to an advertising account. Do not use another site's account ID by assumption.
